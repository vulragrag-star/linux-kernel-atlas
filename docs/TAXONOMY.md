# TAXONOMY — linux-kernel-atlas

Sibling of [uefi-firmware-atlas](https://github.com/vulragrag-star/uefi-firmware-atlas). Same closed-loop stages and use-tags.

## Inclusion
Linux kernel source/security tooling (syzkaller, KASAN/KMSAN/KFENCE, syzbot, kernel CTF, LPE research indexes, rootkit research).

## Exclusion
UEFI/BIOS, IoT router firmware dumps, RTOS, MCU bare-metal, userspace-only Awesome-Linux software lists.

## Stages
spec | acquire | parse | static_re | emulate_fuzz | runtime_assess | offense_poc | defend_harden | vuln_intel | dataset | paper_map | lab_teaching
